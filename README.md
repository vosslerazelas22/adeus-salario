# Adeus Salário 💸

Aplicativo PWA para controle compartilhado de gastos domésticos.

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Realtime

## Funcionalidades

- Login com Supabase Auth
- Controle compartilhado de despesas
- Atualização em tempo real
- PWA instalável
- Interface responsiva
- Temas personalizados por usuário

## Configuração

Crie um arquivo `.env.local` com:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

Depois execute:

```bash
npm install
npm run dev
```
